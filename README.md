# Семейная книга рецептов

Статический двуязычный сайт семейных рецептов. Главная страница проекта — `index.html`; она открывает `family_recipes.html`. Изображения сайта находятся в `recipe-images/`.

## Публикация через GitHub Pages

1. Создать публичный GitHub-репозиторий и отправить в него содержимое этого проекта.
2. Открыть **Settings → Pages**.
3. В разделе **Build and deployment** выбрать **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. После публикации GitHub покажет адрес сайта в этом же разделе.

Исходные файлы рецептов DOCX намеренно исключены из репозитория. Сайт использует Google Apps Script endpoint для уведомлений формы и просмотров.
